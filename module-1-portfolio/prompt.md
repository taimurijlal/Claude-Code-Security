Build a professional, modern personal portfolio landing page based on my LinkedIn profile:

Design Vision:

Cybersecurity-themed aesthetic — dark mode, terminal/matrix-inspired accents, subtle glitch effects, neon highlights (electric blue, cyber green)
Clean, bold typography with smooth scroll animations and micro-interactions
Mobile-first, fully responsive, fast-loading
Use the best modern stack for this (Next.js + Tailwind CSS + Framer Motion recommended, but you decide what delivers the most polished result)

About — Professional summary pulled from my LinkedIn profile

Skills & Expertise — Visual representation of technical skills (security, cloud, DevOps, AI-assisted development)
Experience Timeline — Career journey in a clean, interactive timeline
Contact/Connect — LinkedIn, GitHub, professional links

Agent Team — Execute with these roles:

Researcher — Scrape and analyse my LinkedIn profile for all relevant content, bio, experience, skills, certifications
UI/UX Designer — Define the design system, colour palette, component library, layout wireframe before any code is written
Content Writer — Craft compelling copy for every section — punchy, professional, no fluff
Developer — Build the complete site using the agreed design system and content
QA Lead — Review every agent's output for quality, consistency, responsiveness, accessibility, and performance. Flag issues back to the responsible agent for fixes. Nothing ships until QA approves

All assets optimised, no placeholder content
Production-ready code, not a prototype

Install any missing dependencies. Use all available capabilities. Deliver a complete, deployment-ready project.
