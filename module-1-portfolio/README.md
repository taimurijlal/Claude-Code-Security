# Module 1 - Have Claude Code Create Your Portfolio

## Key Concept

Claude Code is not a chatbot. It is an agentic system that reads files, writes files, executes commands, and modifies your codebase autonomously. It operates inside your development environment, not in a separate chat window. This is fundamentally different from pasting code into ChatGPT.

In this module, you will give Claude Code a single comprehensive prompt and watch it build a complete, deployment-ready portfolio site from scratch.

## What You Will Learn

- How Claude Code operates as an autonomous agent in your terminal
- How to structure prompts that define agent roles (Researcher, Designer, Writer, Developer, QA)
- The difference between chatbot-style prompting and agentic prompting

## Instructions

1. Open your terminal and navigate to an empty project directory
2. Launch Claude Code: `claude`
3. Copy the prompt from [`prompt.md`](prompt.md)
4. Replace the LinkedIn profile placeholder with your own profile URL
5. Paste the prompt and let Claude Code execute

Claude will install dependencies, scaffold the project, generate content, and build a production-ready site autonomously.
